# 【为军服务进行时】心理服务进军营 给官兵注入“心”动力

> 更新时间：2026-09-16 (UTC+8)

**心理服务进军营**

**官兵注入“心”动力**

连日来，医院精神心理科派出两支心理服务队，深入到驻鲁部队基层单位，通过**开展一次心理健康筛查，授一堂心理健康科普课，实施一次心理访谈，带教一批心理骨干，做一次团体训练的“五个一”心理健康服务活动**，将心理健康工作做实做细。切实帮助基层官兵释放压力，使得心理服务工作真正的入心入脑。

**传递“心”健康**

因单位驻地分散，医院心理服务队通过视频连线的方式分别给所属单位进行授课。通过授课让官兵对于“如何看心理”，“心理科都看啥病”，“心理学与精神医学的区别与联系”，“如何减少心理压力保持健康”，“如何消除到精神心理科就医的病耻感”等常见问题获得比较清晰的了解与认识。

“在面对问题时，自己存在偏执，不肯“弯腰”去理性地分析和处理。或许这就是所谓的死要面子，接触了心理健康教育之后能够换个角度看问题，理性的处理问题”。听完专家授课后，某单位战士说道。

**融入“心”世界**

活动中，服务队通过视频连线组织心理健康访谈，对心理健康筛查预警人员逐一实施风险排查，防止因心理问题诱发风险行为，身体健康损害及事故案件的发生。

服务队还带去了脑功能测试仪等一些新型临床心理检查设备，专家现场给官兵展示了新设备的使用及测试结果的解读。现场吸引了很多官兵踊跃前来测试，消除了一些官兵对自己心理健康筛查的不解和疑惑，也很好地**解决了传统的心理健康服务中“反复测”、“题会背”、“没反馈”等现实困难**。

**助力“心”服务**

另外，心理专家帮助指导了基层心理服务站室的软硬件建设，并通过医院伤病员管理科积极协调下**成功****开通了基层官兵精神心理专科就医绿色通道**。切实为基层单位官兵心理减压开展优质服务，为提高部队医院保障打赢能力提供扎实保障。

“通过此次活动，在960医院心理专家的帮助下，让我们这些管理者拓宽了管理思路，清晰地了解到自己官兵心理情况，帮助我们更好地、更实际的去评估自己的管理对象，并实施科学有效管理”。该仓库领导在体验完心理服务后感叹道。

医院组织的本次心理服务活动以**“专业一体、上下联动、融合释能”**的模式，不仅发挥了医院科学指导价值，也缓解了小散远单位就医不便的现实困难，受到基层官兵的一致好评。

心理服务工作是部队一项经常性基础工作，官兵的心理健康直接影响部队战斗力。近年来，医院高度重视这项经常性工作，利用心理服务巡诊、帮助基层建立服务点，开通服务绿色通道等方式，**为他们****架起一座座“连心桥”，持续浇灌官兵们的“心”高地。**
